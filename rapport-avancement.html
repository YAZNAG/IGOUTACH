Invariants — vrais dans le code actuel

Stock global = Σ (stock par lieu) + marchandise en transit
stock_movements : aucun UPDATE ni DELETE — corrections par mouvements inverses
Isolation : un utilisateur ne voit que ses lieux (sauf stock.view_global)
Un inventaire validé ne modifie jamais le CMUP — seulement les quantités

Ordre recommandé pour la suite

  1. Interface POS tactile + ticket de caisse (la vente back-office existe déjà)
  2. Rapports analytiques (ventes, marges, rotation) + règles d'alertes paramétrables
  3. Factures d'achat + règlements fournisseurs (clôt le cycle achats)
  4. Finitions inventaire : gel snapshot, types, double comptage
  5. Appli mobile vendeur (mon stock, vente, encaissement, hors ligne)
